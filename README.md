# EyeKnow - 眼动感知的算法学习认知负荷评估平台

> **Role: Product Lead (产品负责人)**  
> **Status: Beijing Municipal Innovation Project (北京市级大创项目)**

## 📌 项目简介
针对算法学习中“认知黑箱”的痛点（学生不知道自己是累了还是不会，教师看不到学生的解题过程），EyeKnow 通过普通摄像头实时捕捉眼动数据，结合 187 维特征体系与双层机器学习算法，实现毫秒级的认知负荷量化评估。

## 🎯 我的核心职责
- **需求与架构**：主导设计“采集-特征-模型-应用”四层产品整体架构；独立撰写完整 PRD 并制定功能优先级（P0/P1）。
- **用户调研**：深度访谈目标用户，提炼出“过程反馈缺失”等核心痛点，确立产品定位。
- **商业规划**：完成竞品分析，敲定“低成本、非侵入”差异化路线；设计 C 端免费 + B 端增值的商业模式。
- **项目管理**：统筹算法与工程团队推进研发落地，主导赛事路演，项目获评北京市级大创及计算机设计大赛二等奖。
